# Kankia Apple Store Portfolio

A responsive company portfolio for Kankia Apple Store, built with HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` in a browser, or serve the folder with any static server.

## Current scope
- Company overview and international sourcing
- Devices and accessories
- Kankia iCare repair and support
- Device quality and transparency notes
- Kano contact details and WhatsApp links
- Founder profile and detailed product showcase reserved for a future update

The supplied brand logo is in `assets/kankia-logo.jpg`.
